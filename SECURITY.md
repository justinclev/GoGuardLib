# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub's
"Report a vulnerability" button on the repository's Security tab, or email the
maintainer. Include the version, what you observed, and how to reproduce it.

You can expect an acknowledgement within 3 working days and a fix or a plan
within 30 days. Reporters are credited unless they ask not to be.

## Supported versions

Until v1.0, only the latest release receives fixes.
